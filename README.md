# simple-webgui-welle-cli
This is an addon to the Welle-cli that allows for a simplified webgui suitable for phonescreens.
The files are AI edited versions of the original AlbrechtL/welle.io project.

Installation.
1. Install Welle.io (https://github.com/AlbrechtL/welle.io)
2. Find the webgui html folder (most ofte /usr/share/welle-io/html)
3. Make copies of existing index.html file.
4. Replace Index.html file and add the player.js file.

Restart normally should not be nessesary. the new webgui can by default be found at http://ip:8080.
